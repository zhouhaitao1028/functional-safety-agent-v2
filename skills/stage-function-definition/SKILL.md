# 功能定义 Skill（样式模板）

> 本 skill 由具体干活的工程师维护。每个环节的 skill 至少回答三个问题：用到哪些指南模板、模板有哪些易错点、什么情况下参考另一个指南。

## 用到的指南模板

- `gd-function-definition` 功能定义编写指南（主指南，按第 2 节要求逐条检查）
- `tp-function-model` 功能清单模板（产出物格式，表格列不得增删）

## 易错点

- 【待补充：由该环节工程师填写本环节评审中最常打回的问题】
- 【示例】运行场景只写高速巡航，漏掉泊车和低速挪车场景

## 跳转参考

- 【示例】当功能涉及自动驾驶横向控制时 → 参考 `gd-hara-analysis` 的场景枚举要求，提前对齐场景粒度
- 【待补充：其他跳转条件】
