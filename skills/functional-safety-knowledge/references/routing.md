# Knowledge routing

| Need | Route |
| --- | --- |
| Find a method, definition or company rule | Hybrid lexical/vector retrieval |
| Find the exact source paragraph, table row or worksheet | Retrieval plus raw asset locator |
| Identify which guide governs a template | Knowledge graph |
| Analyze requirement-to-test or clause-to-artifact impact | Knowledge graph, then retrieve each supporting source |
| Fill or render an approved Word/Excel template | Template asset service through `document_engineer` |
| Calculate ASIL, FTA cut sets or coverage | Deterministic service; retrieve only the rule provenance |
| Browse and review knowledge manually | Generated Wiki |

Do not put project-specific inputs into global knowledge automatically. Historical outputs become examples only after anonymization, review and explicit promotion.
