# 接口表工具 SKILL 生成指令书

> 用途：把本文件整体发给 Audit-Agent（Head），要求它生成一个可复用的 SKILL。
> 技能归属：05_软件安全架构（ISO 26262 Part 6 §7）；单元级接口明细可同时被 06_软件单元设计与实现（Part 6 §8）引用。
> 事实来源：《接口表生成与对比工具1030详细操作手册》+ 对真实工具与产物的逐项核验结果。

## 第二部分：机器可读使用指南（SKILL 的知识蓝本）

### 1. 技能定位与触发条件

**能做的事**：匹配、汇总、补链路、对比。
- 匹配：给每个接口 XLSM 找到对应软件单元、组件、SWC（模块1）。
- 汇总：把所有接口 XLSM 的信号收拢成一张总览表（模块4）。
- 补链路：生成内部/外部映射与跨应用层 SWC 链路 AA/AB（Python 后处理）。
- 对比：新旧接口表对比、Unit 配置内外部检查。

**触发场景**：
- 生成或重新生成软件组件接口收发总览表；
- 检查总览表 AA/AB 是否正确、定位链路缺失原因；
- 生成下游输入/输出接口补齐清单；
- 标注未参与判定的接口行；
- 新旧接口表或 Unit 配置差异对比。

**不适用**：单元测试、集成测试报告（属 07/08/09 工作产品）。

### 2. 运行环境

| 依赖 | 要求 |
|---|---|
| 操作系统 | Windows |
| Excel | 必须安装，支持 COM 自动化与 VBA 宏；WPS 需单独验证 |
| Python | 可用，含 openpyxl；pandas 可选 |
| exe 工具 | 仅有人值守时使用；无人值守不启动 |
| 不需要 | Docker、OpenClaw（本技能不依赖） |

**无人值守三原则**：Excel `Visible=False`；禁止 MsgBox 阻塞；所有路径用绝对路径。

### 3. 目录契约

```text
<项目根目录>
├─ Inputs
│  ├─ 01_PIE_400\            所有模块接口 XLSM（信号词典，必须含工作表「信号和参数定义」）
│  ├─ 02_PIE_Matrix\         PIE_Matrix_Res_*.xlsx（信号对外路由矩阵）
│  └─ 03_UnitConfig\
│     ├─ 接口表Mapping工具_*.xlsm        含模块1、模块4
│     ├─ Unit2ComponentConfig.xlsx       必须保留此无后缀文件名
│     └─ Unit2ComponentConfig(PIE数字).xlsx  老配置，仅配置对比时需要
├─ Outputs
│  ├─ 01_接口收发表\         软件组件接口收发总览表_YYYYMMDD_HHMMSS.xlsx（每次新增，不覆盖）
│  └─ 02_变更对比\           V2对比结果、Unit内外部配置检查结果
├─ Backups\                  自动备份，可回退
└─ Logs\                     improved_run_*.log、compare_*.log
```

**输入校验规则**：
1. 接口 XLSM 与矩阵表必须存在，否则模块4 读不到数据。
2. `Unit2ComponentConfig.xlsx` 必须无后缀，工具按此文件名查找。
3. 执行前必须关闭所有输入工作簿；发现 `~$<文件名>` 锁文件即判定输入被占用。
4. 老目录无需手工整理，工具会自动迁移旧格式输入到 Inputs 三个子目录。

### 4. 标准执行流程

**阶段 A 预检**
1. 校验目录与必需文件存在性；
2. 扫描 `~$*.xlsx / ~$*.xlsm` 锁文件，发现即报错并列出文件名，提示关闭 Excel/WPS，不强行删除锁文件；
3. 校验接口 XLSM 含「信号和参数定义」；
4. 备份 Mapping、Unit 配置和已有总览表到 Backups。

**阶段 B 生成（两条路径）**

- **路径 B1（默认，无人值守）**：用 Excel COM 打开 Mapping 工具副本，依次运行**模块1**（更新 Unit 配置匹配关系）、**模块4**（汇总生成总览表），再执行 **AA/AB 后处理**。Excel 设为不可见。
- **路径 B2（有人值守）**：运行 exe「一键生成」，依次完成 11 步：检查输入 → 备份 → 检测自动化环境并建临时工作区 → 汇合输入 → 模块1 → 模块4 → Python 补 AA/AB → 写回 Unit 配置与 Mapping → 写出总览表 → 追加变更记录 → 删除临时工作区。期间可能出现"模块1运行完成"等提示框，需人工确认。

**阶段 C 校验**
1. 模块1 运行报告：无大量未匹配、无重复软件单元名；
2. 处理结果汇总：总文件数、成功数、跳过数与预期一致；
3. 文件处理日志：无"函数主流程错误"、无写入失败；
4. MidSheet：P 列文件名、Q/R/S/T 列无空值、无大量"未匹配"；
5. Sheet1：B 列模块名、O 列信号 Mapping 非空，E 列上下游关系合理；
6. AA/AB：按第 5 节规则独立重建校验。

**阶段 D 输出**
1. 总览表（带时间戳，新增不覆盖）；
2. 链路缺失诊断与下游补齐清单；
3. 未参与判定标注副本（如需要）；
4. 校验报告（覆盖范围、检查项、结果、未决项）。

### 5. Sheet1 字段定义

| 列 | 字段 | 说明 |
|---|---|---|
| A | 序号 | 00001、00002… |
| B | 模块名字 | 信号所属模块/单元 |
| C | Signal方向 | Input 或 Output |
| D | 传参方式 | GV 或 RTE |
| E | Signal上下游方 | 发送方/接收方 |
| F | PP接口/Topic接口 | 接口或 Topic 名 |
| G | DataType接口（一级） | 一级数据类型 |
| H | DataType接口（二级） | 二级数据类型 |
| I | Signal接口 | 具体信号接口名 |
| J | Signal中文含义 | 信号说明 |
| K | 数据类型 | uint8、boolean 等 |
| L | coding取值 | 编码或枚举含义 |
| M | 维度 | 信号维度 |
| N | 所属Runnable | 通常为空 |
| O | 信号Mapping | 接口映射键，链路分组依据 |
| P–Z | 空列 | 保留 |
| AA | 跨应用层SWC链路流 | 输出模块→输入模块 |
| AB | 跨应用层SWC信号流 | 输出信号→输入信号 |

### 6. AA/AB 链路判定规则（必须固化进 SKILL）

1. **分组**：按 O 列「信号Mapping」分组，mapping 形如 `Pp...|Dt...|信号名`。
2. **参与判定的范围**：只有命中 Unit 配置「外部组件映射配置」中标记为「剔除，不做任何处理」的 mapping 前缀，才参与跨应用链路判定；未命中的组**不参与判定**，AA/AB 留空。
3. **端点过滤**：`ACF-ACFService`、`FM-FMService`、`MCF-MCFService`、`RCF-RCFService`、`FMB-FMBService` 五个 Service 适配层不作为最终端点。
4. **有效链路**：同组内恰好 1 个有效 Output 且至少 1 个有效 Input。
   - AA = `输出模块→输入模块1,输入模块2,...`
   - AB = `输出信号→输入信号`（输入信号去重）
5. **缺失**：不满足上述条件即标 `链路流信号流缺失`，并分类：缺少有效 Output、缺少有效 Input、多个有效 Output、仅含适配层。
6. **空白不等于正常**：未参与判定的行必须单独统计并说明；需要显性化时在副本中整行填浅黄色（FFF2CC），AA 写入未判定原因。
7. **缺失归因顺序**：先查矩阵是否存在 Outport 源头，再查 `Unit_Name_Out/Name_Out`（发送单元认领）、`Unit_Name_In/Name_In`（接收单元认领），最后查是否 Reserved/Resd 保留位；保留位不得未经确认直接派给下游。

### 7. 量化验收标准

| 项 | 标准 |
|---|---|
| 行数与模块集合 | 与输入重算结果一致；单元分表行数与 Sheet1 对应模块一致 |
| 必填列 | B、C、O 列无空值；无整行重复 |
| AA/AB | 独立重建校验 0 错误；参与判定组数、有效组数、缺失组数三方一致 |
| 缺失清单 | 每组含处理类型、完整 mapping、信号、矩阵发送/接收单元、建议责任单元、词典依据 |
| 未判定行 | 有数量统计与原因说明；标注副本与原文件逐格差异仅限标注单元格 |
| 原文件保护 | 原始输入文件修改时间与内容未被改变 |

**注意**：历史基线（例如某次生成 61 个单元、6,495 单元行、87 组缺失）只能用于比对参考，必须随输入重新计算。

### 8. 异常处理

| 异常 | 处理 |
|---|---|
| 存在 `~$` 锁文件 | 报错并列出文件，提示关闭 Excel/WPS 后重试；不删除锁文件、不继续生成 |
| 缺少接口 XLSM / 矩阵 / 无后缀 Unit 配置 | 中止并列出缺失项 |
| 宏被禁用或 COM 失败 | 检查 Excel 宏安全设置与进程残留；不改用源码修改绕过 |
| MsgBox 阻塞 | 使用后台不弹窗的 Mapping 版本；不启动 exe 界面 |
| 外部目录读取需授权 | 先申请权限，获批后续跑 |
| openpyxl 保存风险 | 文件含图表、x14 数据验证、条件格式时禁止用 openpyxl 落盘，改用 Excel COM |
| 中文乱码 | 脚本与数据文件统一 UTF-8；PowerShell 脚本含中文时用 UTF-8 BOM |
| 生成失败 | 查 Logs 最新日志末尾 ERROR 行，定位后重跑，不降级交付 |

### 9. 禁止事项

1. 禁止修改 VBA 源码与 exe（用户明确要求除外）。
2. 禁止覆盖原始输入文件与历史总览表。
3. 禁止把 Service 适配层当作软件单元端点。
4. 禁止把 AA 空白解释为链路正常。
5. 禁止用理论推测代替实际运行与回读验证。
6. 禁止把历史行数、历史缺失数硬编码为验收期望。
7. 禁止在未确认责任单元前，把保留位信号直接派发给下游。
