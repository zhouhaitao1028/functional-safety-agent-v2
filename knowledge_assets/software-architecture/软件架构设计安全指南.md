# 软件架构设计安全指南

> 对应 ISO 26262-6 第 7、8 章。本指南约束 FSR 向软件架构元素的分配与免于干涉（FFI）设计。

## 1. 输入

- 已批准的 FSR 清单（`tp-fsr-list` 产出）
- 软件架构设计文档（组件、接口、调度）

## 2. 设计要求

1. **分配**：每条 FSR 分配到唯一架构元素；跨元素分配时按 ASIL 分解处理并附独立性论证。
2. **ASIL 分区**：架构元素标注其承载的最高 ASIL；不同 ASIL 元素间接口做免于干涉设计。
3. **FFI 检查**：低 ASIL 元素不得干扰高 ASIL 元素（内存、时序、通信）；列出干涉点与防护机制。
4. **追溯**：架构元素 ↔ FSR 双向追溯表随架构文档交付。

## 3. 易错点（评审重点）

- 承载 ASIL 标注取「曾承载过」而非「当前承载」的最高等级
- FFI 只做内存防护，漏掉时序与通信干涉
- 架构变更后追溯表未同步更新

## 4. 产出与追溯

架构分配表：ARCH-xxx ↔ FSR-xxx 双向追溯。下游进入测试环节（`verification-testing`）。
